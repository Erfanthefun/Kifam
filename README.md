# Kifam

اپ ساده‌ی باقی‌مانده، اقساط و بدهی. وب‌اپ آفلاین (PWA)، فارسی و راست‌به‌چپ، آیفون.

## انتشار
1. یک ریپوی جدید در GitHub بساز (جدا از FI و Vault).
2. همه‌ی فایل‌های این پوشه (به‌جز `tests` اگر نمی‌خوای) را در ریشه‌ی ریپو آپلود کن.
3. Settings > Pages > Branch: main، پوشه‌ی root.
4. آدرس را در Safari باز کن و Share > Add to Home Screen.

## نکته‌ها
- کلید ذخیره‌ی داده `kifam-v1` است؛ هرگز تغییرش نده.
- هر بار آپدیت، مقدار `VERSION` در `sw.js` را بالا ببر.
- حذف آیکون از صفحه‌ی اصلی داده‌ها را پاک می‌کند؛ قبلش بکاپ بگیر. فایل بکاپ را در ریپو آپلود نکن.
- بار اول، موجودی شروع (۳۶٬۷۱۶٬۳۳۴ تومان) و ۷ قسط خودکار وارد می‌شوند.
- میان‌بر تقویم: `Kifam Calendar` (راهنما در تب گزارش).
- اجرای تست‌ها: `bash tests/run.sh`
